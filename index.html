Firebase Realtime Database

Để nhiều điện thoại đồng bộ realtime, tạo 1 Firebase project → Realtime Database → Web App, rồi dán Firebase Config bên dưới. Config được lưu trên trình duyệt. Nên bật Authentication/Database Rules phù hợp trước khi dùng production.

Nếu chưa cấu hình, app vẫn dùng được trên 1 máy ở chế độ local để test luồng.
